Scaled Dot-Product Attention: Scores, Softmax Weights, Weighted Values

Q holds one query vector per row (n_q rows, d_k columns); K holds one key vector per row (n_k rows, d_k columns) so K^T is d_k by n_k; V holds one value vector per row (n_k rows, d_v columns). S = Q K^T gives an n_q by n_k matrix of raw query-key dot products, one row per query.

Why it matters: Each row of S is an unnormalized compatibility score of one query with every key; softmax turns each row into a probability distribution so the output row is a convex combination of the value rows rather than an arbitrary linear combination.

About this lesson

Audience: Second-year engineering undergraduate who knows vectors, matrices and basic probability but has not studied Transformers

Plan: Compute scaled dot-product attention on a 3x2 query matrix, a 2x2 key matrix and a 2x2 value matrix: scores S = Q K^T, scaled by 1/sqrt(d_k) when the toggle is on, then a row-wise softmax for weights A, then A V for the output. Two explorations contrast scaling on versus off and a dominant-score key row against equal scores.

Calculation

No valid result yet.

d_k = 2 for these matrices, the number of columns of Q and K; S = Q K^T, with S[i][j] = q_i . k_j; T = S / sqrt(d_k) when scaling is on, T = S when it is off; A[i][j] = exp(T[i][j] - m_i) / sum_j exp(T[i][j] - m_i), m_i = max_j T[i][j], so each row of A sums to one; O = A V, with O[i][c] = sum_j A[i][j] * V[j][c].

Observe: The scores fed to softmax T equal the raw scores S with entries 1, 0, 0, 1, 1, 1; the weights A become about 0.576, 0.424, 0.424, 0.576, 0.5, 0.5 and the output O becomes about [0.576, 0.424], [0.424, 0.576], [0.5, 0.5].

Explain: With scaling off the softmax exponentials are exp(1) and exp(0) = 1 with max subtracted, so each row of A is exp(1/sqrt(d_k))-weighted; dividing by sqrt(d_k) before the softmax shrinks every score toward 0 and moves A toward the uniform row [0.5, 0.5].

    Limitation

    This page fixes d_k = 2 and n_k = 2 because the key columns and value columns controls supply 2x2 matrices, and fixes n_q = 3 because the query rows control supplies a 3x2 matrix, so the scaling factor 1/sqrt(d_k) is the constant 1/sqrt(2); the general formula keeps the symbol sqrt(d_k) for any key dimension and the general formula keeps its remaining 1/sqrt(d_k) factor whatever that dimension is. Softmax subtracts the row maximum before exponentiating, which leaves the weights mathematically identical to exp(T[i][j]) / sum_j exp(T[i][j]) and only prevents overflow. Softmax is undefined if a whole row of T is -Infinity; no control can produce that, since every matrix entry is finite. Scaling off is a comparison against the paper's procedure, not a procedure the paper uses. This is a toy computation; it does not reproduce any translation result of the paper.

    Source and grounding

    • FROM PAPER Attention Is All You Need — Section 3.2.1, Equation 1

      Attention(Q,K,V) = softmax(Q K^T / sqrt(d_k)) V, so the scores are divided by sqrt(d_k) and the softmax of the result weights the values.

    • FROM PAPER Attention Is All You Need — Section 3.2.1

      The input consists of queries and keys of dimension d_k and values of dimension d_v; we compute the dot products of the query with all keys, divide each by sqrt(d_k), and apply a softmax function to obtain the weights on the values.

    • FROM PAPER Attention Is All You Need — Section 3.2.1, footnote 1

      If the components of q and k are independent with mean 0 and variance 1, then q . k = sum_i q_i k_i has mean 0 and variance d_k, which is the stated reason the dot products grow large and the reason for dividing by sqrt(d_k).

    • TOY EXAMPLE Attention Is All You Need — Figure 2 (left), Scaled Dot-Product Attention

      This page plays the role of the left diagram of Figure 2 with d_k = 2, n_k = 2 and n_q = 3, using the toy matrices Q = [[1,0],[0,1],[1,1]], K = [[1,0],[0,1]], V = [[1,0],[0,1]] as default inputs rather than the paper's trained projections.

    • SIMPLIFICATION Attention Is All You Need — Section 3.2.1

      The row maximum m_i subtracted inside the exponentials is a numerical-stability device added here; the paper states only softmax over Q K^T / sqrt(d_k) and the resulting weights are unchanged.
