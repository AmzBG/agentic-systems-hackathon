Discrete Entropy of a Small Probability Distribution

Audience: A second-year engineering undergraduate at ease using logarithms and elementary probability.

Plan: Learners edit a six-entry weight vector and an outcome count, then see how normalisation produces probabilities, how each probability becomes an entropy contribution, and how the contributions sum to the entropy in bits. Two presets contrast a certain outcome (entropy 0) with four equally likely outcomes (entropy 2 bits).

Starting point

Idea: Entropy H = -sum p_i log2 p_i measures the average uncertainty in bits for a discrete choice having probabilities p_i.

Why it matters: H lets an engineer compare how much information a source produces per symbol and underpins source coding limits.

Explanation: The learner chooses the number of active outcomes n by the Outcome count control and supplies six nonnegative weights w_i by the Weight vector control; the Uniform switch can override the weights. The compute step first activates the leading n weights, replaces negative values by 0, and adds them. If the Uniform switch is on or the total is 0, every active probability is set to 1/n; otherwise each active probability is p_i = w_i divided by the sum of active weights. These Probabilities p_i form the first intermediate output. Next each probability becomes a Contribution c_i = -p_i log2 p_i, using the convention c_i = 0 when p_i = 0, and the Contributions c_i form the second intermediate output. Adding the contributions gives the Entropy H in bits, the main result. The Maximum entropy is log2 n, and the Redundancy is 1 minus H divided by log2 n when n is greater than 1, and 0 when n equals 1. Thus the readouts show how certainty (H = 0) and equally likely outcomes (H = log2 n) arise from one calculation.

Guided explorations

Certain outcome

Predict: Predict: what is the entropy when one outcome has probability 1 and all others 0? Then apply the preset, which sets the outcome count to 4, the weight vector to [1,0,0,0,0,0] and leaves the uniform switch off.

Observe: The probabilities readout becomes 1, 0, 0, 0; every contribution readout is 0 bits, the entropy readout is 0 bits, the maximum entropy readout is 2 bits and the redundancy readout is 1.

Explain: A single certain outcome gives no uncertainty; each term -p log2 p is 0 because either p is 0 or p is 1 and log2 1 is 0, so the total H is 0.

Four equally likely outcomes

Predict: Predict: how large is the entropy in bits when four outcomes are equally likely? Then apply the preset, which sets the outcome count to 4 and turns the uniform switch on.

Observe: The probabilities readout becomes 0.25, 0.25, 0.25, 0.25; each contribution readout is 0.5 bits, the entropy readout is 2 bits, the maximum entropy readout is 2 bits and the redundancy readout is 0.

Explain: When n outcomes are equally likely every p is 1/n, so every contribution is (1/n) log2 n and the total is log2 n; for n=4 the entropy is 2 bits, the largest possible value for four outcomes.

Limitation

The page treats the active weights as a full probability distribution after normalisation, so it cannot show unnormalised weights as meaningful probabilities. The zero-total fallback to uniform is a display convention, not a claim that all-zero weights describe a valid source. The sweep visual reuses the same six weight entries for every outcome count. When n equals 1 the Redundancy is defined as 0 because the Maximum entropy is 0 and division by 0 is not defined.
